# Changelog

## 0.6.2 - 2026-08-31

### Added

- Per-project spellcheck dictionaries for managing added and ignored words, including case-sensitive entries.

## 0.6.1 - 2026-08-31

### Changed

- README now documents the full feature set, including the timeline canvas, notes panel, tags, spellcheck languages, and appearance settings.

## 0.5.1 - 2026-08-31

### Added

- A visual timeline canvas for arranging story events and managing their nodes.

## 0.4.1 — 2026-08-28

Tagged releases publish to itch.io again (macOS, Windows, Linux x86_64, and Linux ARM64).

## 0.4.0 — 2026-08-28

### Added

- Choose the font for the scene and note editors from **Options**. The list includes common writing fonts installed on your system, with a live preview. The rest of the UI is unchanged.
